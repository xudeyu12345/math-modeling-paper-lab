# 数学建模优秀论文分析库 · Math Modeling Paper Lab

中国研究生数学建模竞赛 2021–2025 优秀论文全套分析界面（纯静态站点，GitHub Pages 直接托管）。

## 功能覆盖

| 模块 | 内容 |
|---|---|
| 总览 | 189 篇优秀论文统计：年份/赛题/奖级分布、方法类别五年热度、赛题主题速览 |
| 论文库 | 189 篇结构化画像（标题/摘要/方法标签/结构完整度），多条件筛选+搜索，点击看详情，「📄 查看」在线阅读全文 PDF |
| 深度分析 | 59 篇代表论文人工精读（每年每题 1–2 篇）：论文架构/解决思路/好在哪/可借鉴 |
| 方法论图谱 | 八大方法类别高分用法要点 + 五年方法论趋势总结 |
| 写作指南与量规 | 基于 189 篇反向归纳的评分量规 + 十条写作要点 |
| 自评工具 | 按优秀论文基准打分的结构自检清单 |
| 论文评价系统 | 内嵌 ARS academic-paper-reviewer 全流程：粘贴/上传论文 → Phase 0 领域分析+评审团配置 → Phase 1 五位审稿人独立评审（EIC/方法学/领域/视角/魔鬼代言人）→ 逐部分评审意见（按章节给出 ✓/⚠/✎）→ Phase 2 编辑决议信+修改路线图。对标 189 篇整体基准 + 59 篇精读方法匹配借鉴 |
| 全文阅读 | 论文库每篇论文可点击「📄 查看」在线阅读全文 PDF（托管于 `papers/<年份>/` 目录） |
| 上传分析 | 拖拽上传自己的/往年的建模论文（PDF/DOCX），浏览器本地解析（pdf.js/mammoth，文件不上传服务器），自动识别结构模块与方法体系，对照 189 篇优秀论文基准打分，给出逐条改进建议 + 方法最相似优秀论文参照 |

## 技术说明

- 零依赖纯前端：原生 HTML/CSS/JS，无构建步骤
- 上传分析完全在浏览器本地进行（pdf.js / mammoth.js CDN），论文文件不会离开用户设备
- 189 篇论文画像拆分为 `js/dp_part1/2/3.js` 三个分片，由 `js/data_profiles.js` 合并
- 评价引擎为透明规则化评分（ARS quality_rubrics 5 维量规：创新性20/方法严谨25/证据充分25/论证连贯15/写作规范15），分数仅有次序意义
- 数据来源：本机历年获奖作品目录全文提取与结构化（189 篇画像）+ 59 篇人工精读

## 本地运行

直接双击 `index.html`，或任意静态服务器（如 `npx serve`）。

## 部署

GitHub Pages：Settings → Pages → Deploy from a branch → `main` / `/ (root)`。
